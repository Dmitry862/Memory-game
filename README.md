# Memory Game

## A classic memory card game where players need to find matching pairs.

### Features

- Three difficulty levels: Easy, Medium, Hard

- Random card shuffling

- Move counter

- Game reset

- Win notification

- Technologies

- HTML

- CSS

- JavaScript

### How to play

1. Choose a difficulty level.

2. Memorize the cards during the initial display.

3. Find all matching pairs.

4. Try to complete the game in as few moves as possible.
